# Web services final project

Paprasta užduočių REST API realizacija su PHP ir SQLite. Visi paleidimo, Swagger, Postman ir testavimo žingsniai lietuviškai: [PAAISKINIMAS_LT.md](PAAISKINIMAS_LT.md).

Greita pradžia (PHP 8.2+, `pdo_sqlite`, `mbstring`):

```bash
php -S 127.0.0.1:8000 -t public public/index.php
```

Tada atidaryk <http://127.0.0.1:8000/tasks>. Testai: `php tests/run.php`.
